# QuickDish Frontend

React + TypeScript + Vite frontend for QuickDish.

## Development

1. Fill in `.env` with your Google credentials and the API URL (file is gitignored, not committed).
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Production build: `npm run build`

The full architecture, feature list, environment rules, and backend startup order are documented in the repository root `README.md`.
